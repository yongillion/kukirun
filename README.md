# 디저트 대시 (Dessert Dash) — 프로젝트 `kukirun`

디저트 친구들이 다섯 개의 달콤한 랜드를 달리는 **싱글플레이 웹 러닝 게임**입니다.
자동으로 달리는 캐릭터를 점프·더블 점프·슬라이드로 조종해서 장애물을 피하고, 젤리와 코인을 모으고,
줄어드는 에너지를 우유로 채우며 최대한 멀리, 높은 점수로 달리는 게임이에요.
캐릭터·그림·애니메이션·음악·효과음은 모두 이 프로젝트를 위해 새로 만든 오리지널 에셋입니다.

## 실행 방법

- **그냥 `index.html`을 더블클릭**하면 됩니다 (Chrome / Edge 권장, 인터넷 연결 불필요).
- 로컬 서버로 실행하려면: `node tools/serve.mjs` → <http://localhost:8080/index.html>
  - `dev.html`은 번들 없이 `src/`의 ES 모듈을 바로 불러오는 개발용 페이지예요 (서버 필요).
- 첫 터치/클릭 이후에 소리가 나요 (브라우저 자동재생 정책).
- **온라인 플레이 (GitHub Pages):** <https://yongillion.github.io/kukirun/>
  - 저장소 Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main / (root)** 로 설정하면 배포돼요.
  - 빌드 단계가 필요 없어요 (`dist/game.js`가 저장소에 포함되어 있고, `.nojekyll`로 파일을 그대로 서비스해요).

## 게임 요소

- **러너 7명** — 칩(초코칩 쿠키), 마카(딸기 마카롱), 푸딩, 도넛, 마시(마시멜로), 컵케(컵케이크), 솜이(솜사탕).
  각자 고유 스킬(초코 소나기, 스윗 블룸, 카라멜 힐, 링 롤, 퐁신 플로트, 럭키 스프링클, 구름 쿠션)과 레벨 1~10.
- **펫 5마리** — 반짝이(별 젤리), 붕붕(우유 배달), 몽실(자석), 꿀꿀(금화), 팡팡(장애물 폭파).
- **랜드 5곳 + 반복 회차** — 슈가 메도우 → 캐러멜 캐니언 → 코코아 동굴(떨어지는 종유석) →
  셔벗 빙하(솟아오르는 얼음 가시) → 별사탕 성. 랜드가 바뀔 때마다 속도가 빨라지고, 다 돌면 더 빠르게 다시 시작해요.
- **장애물** — 낮은 가시(점프), 넓은 가시, 높은 기둥(더블 점프), 매달린 장애물·천장 가시(슬라이드), 구멍(점프),
  떠 있는 발판, 스프링, 낙하·돌출 장애물.
- **수집품** — 젤리 7종(기본·핑크·별·왕별·무지개·초대형·초코), 은화/금화/큰 금화, 우유(에너지 회복).
- **아이템** — 자석, 거대화, 로켓 대시, 코인 러시, 별빛 변환, 버블 실드.
- **슈가 러시** — S·U·G·A·R·R·U·S·H 글자 9개를 모으면 하늘 보너스 스테이지로!
- **콤보** — 끊기지 않고 먹으면 점수 보너스(최대 +50%), 부딪히면 초기화.
- **안전장치** — 릴레이(두 번째 캐릭터가 이어 달리기), 부활 부스트, 솜이의 구름 쿠션, 라스트 스퍼트.
- **성장 요소** — 연구소 업그레이드 7종, 출발 전 부스트 5종, 미션 3개(완료 시 코인·경험치),
  플레이어 레벨, 최고 기록·TOP 5 기록, 첫 판 튜토리얼.

## 폴더 구조

```
index.html          ← 실행 파일 (dist/game.js 사용, 더블클릭으로 실행)
dev.html            ← 개발용 (src/ ES 모듈 직접 로드, 서버 필요)
css/game.css
src/                ← 게임 소스 (ES 모듈)
  main.js           게임 셸, 씬 전환, 결과 처리
  config.js         물리·속도·에너지·점수 등 튜닝 값
  engine/           화면, 입력, 오디오, 에셋, UI, 씬, 파티클, 트윈, 저장
  game/             러너, 월드, 레벨 패턴, 생성기, 배경, HUD, 펫, 보너스, 성장
  scenes/           로딩, 타이틀, 로비, 캐릭터, 펫, 연구소, 미션, 출발 준비, 달리기, 결과, 설정
  data/             콘텐츠 데이터 + 자동 생성된 아틀라스·오디오 목록
dist/game.js        ← src/를 하나로 묶은 번들 (자동 생성)
assets/
  img/              캐릭터·펫·배경·장애물·아이템·이펙트·UI 스프라이트 시트 (PNG)
  audio/            효과음 60개 + 배경음악 8곡 + 징글 2개 (MP3), audiopack.js(파일 직접 실행용 묶음)
  fonts/            글꼴 (Noto Sans CJK KR, Poppins — SIL OFL)
tools/
  build.mjs         번들러 (의존성 없음)
  serve.mjs         개발 서버
  art/              그림 생성기 (Canvas 코드 → PNG). modules/ 에 캐릭터·배경 등 그리는 코드
  audio/            사운드 신디사이저 (Python) — 효과음·작곡·믹싱·마스터링
  fonts/            글꼴 서브셋 생성
  test/solver.mjs   모든 레벨 패턴이 모든 속도에서 통과 가능한지 검사하는 솔버
```

## 수정하고 다시 빌드하기

- 코드를 고친 뒤: `node tools/build.mjs` (또는 `node tools/build.mjs --watch`) → `dist/game.js` 갱신.
  개발할 때는 `node tools/serve.mjs` 후 `dev.html`을 열면 빌드 없이 바로 반영돼요.
- 그림 다시 만들기: `node tools/art/export.mjs [모듈명…]` (Playwright + Chromium 필요).
  미리보기는 서버 실행 후 `tools/art/forge.html?modules=characters` 를 브라우저로 열면 돼요.
- 사운드 다시 만들기: `python3 tools/audio/build.py` (numpy, scipy, ffmpeg 필요).
- 글꼴 다시 만들기: `python3 tools/fonts/build_fonts.py` (fontTools 필요).
- 레벨 검사: `node tools/test/solver.mjs` → 모든 패턴 × 속도 조합의 통과 가능 여부 출력.
- 밸런스는 `src/config.js`(속도·에너지·점수)와 `src/data/content.js`(캐릭터·펫·연구소·미션)에서 조절해요.

## 디버그 모드

주소 끝에 `?debug`를 붙이거나 게임 중 `` ` `` 키를 누르면 히트박스·FPS가 보여요.
달리는 중 단축키: `G` 거대화, `M` 자석, `D` 대시, `C` 코인 러시, `V` 별빛, `B` 실드, `L` 글자, `E` 에너지 회복,
`Q` 스킬 발동, `N` 다음 랜드, `O` 에너지 0. 로비에서 `K` 를 누르면 코인 +10,000.

## 저장

진행 상황은 브라우저 localStorage(`dessert-dash-save-v1`)에 저장돼요. 설정 화면에서 초기화할 수 있어요.
